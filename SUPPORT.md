# Support

## Questions and bug reports

Use GitHub Issues for reproducible bugs, build problems, and focused feature requests. Before filing an issue:

- Search for an existing report.
- Reproduce with the latest `main` revision when practical.
- Include the Xcode version, platform, OS version, device class, and model identifier.
- Include relevant logs after removing prompts, conversations, file paths, contact details, and other personal data.

For inference failures, state whether the test used an Apple-silicon Mac or a physical iOS device. The iOS Simulator cannot run MLX inference, AlarmKit, or Live Activities.

This is a community open-source project. Support, compatibility, and response times are not guaranteed.

## Security

Do not report vulnerabilities in a public issue. Follow [`SECURITY.md`](SECURITY.md).
